# Image provenance

This project records where its material comes from. Every melodic fragment in
`src/data/fragments/` carries a source id, a composer, a work and a licence, and
`src/core/fragments.js` refuses anything marked NonCommercial or ShareAlike. The
images shipped in this directory are held to the same standard of disclosure.

## `lyra.webp` — the expedition guide

- **What it is:** a portrait used for Lyra, the in-app reading guide. It appears
  on the guidance station screen inside the 3D room, in the arrival card, and
  beside the practice console.
- **Origin:** generated with an image model for this project. It is not a
  photograph, and it does not depict a real person.
- **Rights:** created for Prima Vista and used only here.
- **Open question:** a photorealistic generated face can resemble people it was
  never meant to. If this ships beyond personal use, replace it with an
  illustrated or abstract guide, or commission a portrait with a licence on
  record. The code paths that use it all degrade to text without it.

## `expedition.webp` — the view beyond the window

- **What it is:** the exterior seen through the station window, and the
  background of the expedition hero.
- **Origin:** generated with an image model for this project. It is an artist's
  impression, not an image of any real body, and it should not be captioned as a
  photograph of one.
- **Rights:** created for Prima Vista and used only here.
