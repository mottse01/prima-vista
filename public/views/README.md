# What is outside each window

One wide image per destination, named for its place: `luna.webp`, `mars.webp`,
`ceres.webp`, `jupiter.webp`, `saturn.webp`, `uranus.webp`, `neptune.webp`,
`pluto.webp`, `kuiper.webp`, `heliopause.webp`.

Anything missing falls back to the shared view in `public/expedition.webp`, so
the set can be replaced one at a time and a half-finished one still leaves
every station with something to look at.

The plane they land on is 48 × 26 world units — roughly **16:9** — sitting
eighteen units behind the observation window, so it reads as a distant view
rather than as wallpaper. Export at 2048 × 1152 or larger, as WebP.

They are seen through window mullions and behind a lit interior, so the
composition should have its interest spread across the frame rather than a
single subject in the middle, and the values should stay in the upper-middle
of the range: a very dark image reads as a hole in the wall.

Record where each one came from in [`../ASSETS.md`](../ASSETS.md).
